# 桌面待办 {{VERSION}}

简洁、透明的 Windows 桌面待办小组件。固定在工作区右上角，默认允许普通窗口遮住，也可切换始终置顶。

## 下载与运行

推荐下载 `DesktopTodo-{{VERSION}}-Windows.zip`，完整解压到可写文件夹，然后双击 `DesktopTodo.exe`。压缩包包含程序、运行配置、使用说明和图标，不含任何待办数据。

也可只下载 `DesktopTodo.exe`，放到可写文件夹后直接运行。ZIP 中的 `.config` 是可选的兼容配置，不是单独运行的必需文件。`SHA256SUMS.txt` 提供 EXE 和 ZIP 的 SHA-256 校验值。

适用于 64 位 Windows 10 / 11，依赖系统已有的 .NET Framework 4.8 或兼容的 4.8.1，程序不内置运行时；无需安装 Python、Node.js、数据库或额外包。可执行文件未进行代码签名。

## 功能

- 半透明底板、清晰文字，透明度及浅深主题可调整。
- 更大的字号和点击区域，面板适度加宽；长事项换行、分类栏和编辑页布局同步调整。
- 初始只有“默认”分类，可自行添加、重命名和整理分类。
- 待办支持新增、编辑、移动、完成和删除，删除后可短时撤销。
- 圆角完成框，以及当前分类内的待办拖动排序；调整后的顺序自动保存。
- 可选 DDL 与倒计时，临近截止时间显示表情、轻吐槽和短暂动效。
- 托盘操作、置顶切换和可选开机启动；提醒仅在程序运行时生效。
- 本地 JSON 保存与有效备份；已完成和已删除事项按日期归档，保留当天及前 29 天，未完成事项一直保留。

## 更新已有程序

先从托盘退出程序，再替换程序文件。保留原有 `data.json`、`data.backup.json` 和 `archive` 文件夹。移动程序目录前请先关闭开机启动，移动完成后重新启用。
